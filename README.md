# Bánh Mì A Huy 🥖

Game nấu bánh mì kiểu Cooking Mama, phong cách chibi, song ngữ Việt/Anh.
A chibi Cooking-Mama-style Vietnamese bánh mì stall web game.

- 7 ngày cốt truyện + Hội thi bánh mì Long Khánh
- Đồ uống: cà phê sữa đá, trà đào cam sả, chanh dây, nước ép
- Chế độ "Bán tới sáng" (endless) sau khi thắng hội thi
- Chơi trên máy tính hoặc điện thoại (xoay ngang)

**Chơi:** mở `index.html` hoặc trang GitHub Pages của repo.

Art & voices generated with AI (Higgsfield: Nano Banana, MiniMax TTS).
